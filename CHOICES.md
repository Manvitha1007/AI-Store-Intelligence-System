# CHOICES.md

## Model Selection

YOLOv8 was selected because it provides:

* High detection accuracy
* Real-time performance
* Easy integration
* Strong community support

## Tracking Selection

ByteTrack was selected because:

* Stable tracking IDs
* Good performance in crowded scenes
* Lightweight implementation

## Event Schema Design

JSON events were chosen because:

* Human-readable
* Easy API integration
* Simple storage and processing

## API Architecture

FastAPI was selected because:

* Automatic API documentation
* High performance
* Easy deployment

## Engineering Trade-offs

A lightweight local architecture was chosen instead of distributed streaming systems to focus on reliability, simplicity, and rapid development within challenge constraints.
